# MaidPatina

**Minecraft Forge** 附属模组，为 **[车万女仆][tlm]** 添加两项铜块养护工作模式 —— **除锈** 与 **涂蜡** —— 以及一项引导蜜蜂采蜜、产蜜的 **高级采蜜** 任务。

**简体中文** | [English](../../README.md)

| | |
|---|---|

| Minecraft | 1.20.1 |
| Forge | 47.4.22 及以上（loader 47+） |

MaidPatina 不添加任何方块、物品或实体，全部功能都以车万女仆的 **女仆任务** 及配套 AI 行为实现，因此可以安全地加入已有存档。

## 功能

### 除锈 —— `maidpatina:rust_removal`

*图标：铁斧*

* **工具：** 任意位于 `maidpatina:rust_removal_tools` 物品标签中的物品，或任意支持 Forge `AXE_SCRAPE` 工具行为的物品（原版斧头开箱即用）。
* **行为：** 工作时女仆会扫描自身周围 3 格范围，只保留位于工作范围之内、视线可达、且存在上一级锈蚀状态的铜块（`WeatheringCopper#getPrevious`），走到最近的一个并 **移除一层锈蚀**。
* 播放原版的刮擦音效与粒子，挥动手臂，并消耗工具 1 点耐久（不可损坏的工具则消耗 1 个物品）。

### 涂蜡 —— `maidpatina:waxing`

*图标：蜜脾*

* **工具：** `minecraft:honeycomb`，或任意位于 `maidpatina:waxing_items` 物品标签中的物品。
* **行为：** 与除锈相同的扫描、寻路与应用流程，但作用于注册在原版 `HoneycombItem.WAXABLES` 中的方块。
* **模组兼容：** 1.20.1 的 Create 会在 common setup 阶段把自身的铜块注入原版映射表，因此 Create 的铜块同样可以涂蜡；其他做了相同注入的模组也一并适用。
* 播放原版的涂蜡音效与粒子，并消耗 1 个物品。

### 高级采蜜 —— `maidpatina:advanced_honey`

*图标：蜂蜜瓶*

该任务取决于女仆身上展示的物品，需要同时满足三个条件：

| 条件 | 位置 | 判定 |
|---|---|---|
| 蜂巢 | 头饰位、主手或副手 | `minecraft:beehive` 或 `minecraft:bee_nest` |
| 花朵 | 头饰位、主手或副手 | 任意属于 `#minecraft:flowers` 的物品 |
| 采集工具 | 女仆背包 | 剪刀（Forge `SHEARS_HARVEST`）或 `minecraft:glass_bottle` |

花朵与蜂巢都按 **头饰位 > 主手 > 副手** 的优先级查找，并且必须位于 **不同** 的位置（同一个物品不可能既是花朵又是蜂巢）。任务界面会列出这三项条件，缺少任意一项女仆都不会开始工作。

工作循环：

1. **预约蜜蜂** —— 20 格内最近的可用蜜蜂。可用条件为：成年、存活、未愤怒、未留下螫针、没有攻击目标、身上没有花蜜、接受女仆手持的花朵（`Bee#isFood`），且未被其他女仆预约。若女仆中途中断，预约保留 5 秒；单次工作最长 60 秒。
2. **采蜜（5 秒）** —— 女仆原地站定并朝向固定角度，把蜜蜂引到花朵所在的交互点：头饰位为头顶上方，手部则位于对应手的一侧。蜜蜂在交互点保持 5 秒后，女仆将其标记为携带花蜜。
3. **产蜜（2 秒）** —— 女仆用同样的方式把蜜蜂引到蜂巢所在的交互点并保持 2 秒。随后将 **1 个蜜脾**（消耗剪刀 1 点耐久）或 **1 瓶蜂蜜**（消耗 1 个玻璃瓶）存入背包，播放原版采集音效，蜜蜂同时卸下花蜜。
4. **冷却** —— 该蜜蜂 5 分钟内不会被再次使用。若背包已满或采集工具不在，则不会产出蜂蜜，女仆直接重新开始。

### 除锈 + 涂蜡连携

面对锈蚀铜块时，涂蜡女仆无法直接涂蜡，此时她会请求协助而不是放弃：

* 她会呼叫 16 格内 **同一主人** 的最近的 **除锈女仆**。协助者需要处于 `WORK` 作息、能够移动、能够破坏该方块，并携带除锈工具。
* 协助者走过来后，**每 10 tick（0.5 秒）移除一层锈蚀**，直到该方块可以涂蜡。
* 涂蜡女仆全程在旁等待并注视协助者；一旦方块可涂蜡，且她在 3 格以内且视线可达，就 **由她自己完成涂蜡** —— 协助者不会代为涂蜡。
* 完成后涂蜡女仆会看向协助者、挥动副手、生成爱心粒子并播放道谢音效。
* 该连携关系是健壮的：找不到协助者、请求在 20 秒后超时、协助者死亡/被改派/失去工具时，涂蜡女仆都会 **独自完成工作**。方块同样会被预约，两名涂蜡女仆不会争抢同一方块。

## 数据驱动的工具标签

两套工具都由物品标签控制，整合包与数据包无需改动代码即可扩展或替换：

`data/maidpatina/tags/items/rust_removal_tools.json`

```json
{
  "replace": false,
  "values": [
    { "id": "create:sand_paper", "required": false },
    { "id": "create:red_sand_paper", "required": false }
  ]
}
```

`data/maidpatina/tags/items/waxing_items.json`

```json
{
  "replace": false,
  "values": [
    "minecraft:honeycomb"
  ]
}
```

由于同时接受 Forge 的 `AXE_SCRAPE` 行为，数据包只需补充特殊工具（例如已在标签中作为可选条目列出的 Create 砂纸）—— 普通斧头始终可用。除标签之外，除锈任务还接受任何启用了刮擦行为的物品。
